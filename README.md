# 🍱 Meal Point

A web-based Meal Point platform that provides healthy, hygienic, and homemade food through an easy online system.

## 🚀 Live Demo

👉 [Visit Meal Point Website](https://meal-point-c2cs.onrender.com/)

## ✨ Features

* 👤 Customer Registration & Login
* 🍱 View Meal Plans
* 📅 Weekly Meal Schedule
* 💳 Payment Management
* ⭐ Customer Feedback & Ratings
* 📩 Contact & Query System
* 🖼️ Cloudinary Image Storage
* 🔐 Admin & Manager Management

## 🛠️ Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Cloudinary
* Bootstrap

## 👥 User Roles

### Admin

* Manage the portal
* Manage managers
* View reports

### Manager

* Manage meal plans
* Manage customers
* Manage payments
* Manage queries and feedback

### Customer

* Register and login
* View meal plans
* Purchase meal plans
* Make payments
* Give feedback and ratings

## 🌐 Deployment

The project is deployed using Render.
